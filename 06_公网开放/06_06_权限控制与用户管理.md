# 权限控制与用户管理

当你的应用对公网开放后，如何管理用户的访问权限就成了重要课题。这一章将教你实现安全的用户认证和权限管理，保护你的应用不被滥用。

---

## 一、认证与授权基础

### 1. 基本概念

**认证（Authentication）**：验证"你是谁"
- 用户登录时验证身份
- 确保访问者是合法的用户本人

**授权（Authorization）**：决定"你能做什么"
- 验证用户权限
- 决定用户可以访问哪些资源

### 2. 常见认证方式

**用户名密码认证**：
- 最传统的方式
- 用户注册时设置密码
- 登录时验证密码

**验证码认证**：
- 手机验证码
- 邮箱验证码
- 用于防止自动化攻击

**第三方登录**：
- 使用微信、GitHub、Google等账号登录
- 减少用户注册成本
- OAuth 2.0协议

**生物识别**：
- 指纹、面部识别
- 主要用于移动端

## 二、常见的认证方式实现

### 1. 用户名密码认证

**用户注册流程**：
```
用户输入 → 前端验证 → 后端验证 → 密码加密 → 存储到数据库
```

**用户登录流程**：
```
用户输入 → 后端验证密码 → 生成Token → 返回给前端 → 前端保存Token
```

### 2. JWT令牌机制

JWT（JSON Web Token）是目前最流行的认证方案之一。

**JWT结构**：
```
xxxxx.yyyyy.zzzzz
 │      │     │
 │      │     └── Signature（签名）
 │      └────── Payload（负载）
 └────────────── Header（头部）
```

**Header**（头部）：
```json
{
  "alg": "HS256",
  "typ": "JWT"
}
```

**Payload**（负载）：
```json
{
  "sub": "1234567890",
  "name": "John Doe",
  "role": "user",
  "exp": 1699999999
}
```

**Signature**（签名）：
```javascript
HMACSHA256(
  base64UrlEncode(header) + "." + base64UrlEncode(payload),
  secret_key
)
```

**JWT优缺点**：
- 优点：无状态、可扩展、支持跨域
- 缺点：无法在服务端主动失效

### 3. 实现示例（Python/FastAPI）

**安装依赖**：
```bash
pip install python-jose passlib[bcrypt] python-multipart
```

**密码加密存储**：
```python
from passlib.context import CryptContext

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

def hash_password(password: str) -> str:
    return pwd_context.hash(password)

def verify_password(plain_password: str, hashed_password: str) -> bool:
    return pwd_context.verify(plain_password, hashed_password)
```

**生成JWT Token**：
```python
from datetime import datetime, timedelta
from jose import jwt

SECRET_KEY = "your-secret-key"
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 30

def create_access_token(data: dict, expires_delta: timedelta = None):
    to_encode = data.copy()
    if expires_delta:
        expire = datetime.utcnow() + expires_delta
    else:
        expire = datetime.utcnow() + timedelta(minutes=15)
    to_encode.update({"exp": expire})
    encoded_jwt = jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)
    return encoded_jwt
```

**验证Token**：
```python
from fastapi import Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer
from jose import JWTError

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

async def get_current_user(token: str = Depends(oauth2_scheme)):
    credentials_exception = HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail="Could not validate credentials",
        headers={"WWW-Authenticate": "Bearer"},
    )
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        username: str = payload.get("sub")
        if username is None:
            raise credentials_exception
    except JWTError:
        raise credentials_exception
    return username
```

## 三、密码安全

### 1. 密码加密存储

**绝对不要**以明文存储密码！使用强哈希算法：

```python
# 使用bcrypt（推荐）
from passlib.context import CryptContext
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

# 注册时
hashed = pwd_context.hash("user_password")

# 登录时验证
pwd_context.verify("user_password", hashed)  # True
```

### 2. 密码强度要求

强制用户使用强密码：
- 至少8个字符
- 包含大小写字母
- 包含数字
- 包含特殊字符

### 3. 防止暴力破解

**登录限流**：
```python
from slowapi import Limiter
from slowapi.util import get_remote_address

limiter = Limiter(key_func=get_remote_address)

@router.post("/login")
@limiter.limit("5/minute")
async def login(request: Request):
    # 登录逻辑
```

**验证码**：
- 登录失败5次后要求输入验证码
- 锁定账户15分钟

## 四、用户权限管理

### 1. 角色权限模型

常见的权限模型：

```
用户 ──┬── 管理员（admin）
      │
      ├── 编辑（editor）
      │
      └── 普通用户（user）
```

**权限矩阵**：
| 功能 | 管理员 | 编辑 | 用户 |
|------|--------|------|------|
| 管理用户 | ✓ | ✗ | ✗ |
| 发布内容 | ✓ | ✓ | ✗ |
| 查看内容 | ✓ | ✓ | ✓ |

### 2. 基于角色的访问控制（RBAC）

**数据库设计**：
```sql
-- 用户表
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    role VARCHAR(20) DEFAULT 'user'
);

-- 权限表
CREATE TABLE permissions (
    id SERIAL PRIMARY KEY,
    name VARCHAR(50) UNIQUE NOT NULL,
    description TEXT
);

-- 用户权限关联
CREATE TABLE user_permissions (
    user_id INTEGER REFERENCES users(id),
    permission_id INTEGER REFERENCES permissions(id),
    PRIMARY KEY (user_id, permission_id)
);
```

**代码实现**：
```python
from enum import Enum

class UserRole(str, Enum):
    ADMIN = "admin"
    EDITOR = "editor"
    USER = "user"

# 权限检查装饰器
def require_role(role: UserRole):
    def decorator(func):
        async def wrapper(current_user = Depends(get_current_user)):
            if current_user.role != role.value and current_user.role != UserRole.ADMIN.value:
                raise HTTPException(status_code=403, detail="权限不足")
            return await func(current_user)
        return wrapper
    return decorator

# 使用示例
@router.delete("/users/{user_id}")
@require_role(UserRole.ADMIN)
async def delete_user(user_id: int, current_user = Depends(get_current_user)):
    # 删除用户逻辑
    pass
```

## 五、接口访问控制

### 1. 公开接口 vs 受保护接口

```python
from fastapi import APIRouter, Depends

router = APIRouter()

# 公开接口（无需认证）
@router.get("/public/info")
async def get_public_info():
    return {"message": "公开信息"}

# 受保护接口（需要认证）
@router.get("/protected/data")
async def get_protected_data(current_user = Depends(get_current_user)):
    return {"message": f"欢迎 {current_user.username}"}
```

### 2. API Key认证

除了用户登录，还可以使用API Key进行接口认证：

```python
from fastapi import Header

@router.get("/api/data")
async def get_data(x_api_key: str = Header(...)):
    # 验证API Key
    if not validate_api_key(x_api_key):
        raise HTTPException(status_code=401, detail="无效的API Key")
    return {"data": "some data"}
```

### 3. CORS跨域配置

当你的前端和后端分离部署时，需要配置CORS：

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://yourdomain.com"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

## 六、安全最佳实践

### 1. 安全头部

使用安全中间件添加HTTP安全头部：

```python
from fastapi.middleware.trustedhost import TrustedHostMiddleware
from starlette.middleware.sessions import SessionMiddleware

# 添加安全头部
@app.middleware("http")
async def add_security_headers(request, call_next):
    response = await call_next(request)
    response.headers["X-Content-Type-Options"] = "nosniff"
    response.headers["X-Frame-Options"] = "DENY"
    response.headers["X-XSS-Protection"] = "1; mode=block"
    response.headers["Strict-Transport-Security"] = "max-age=31536000; includeSubDomains"
    return response
```

### 2. 敏感数据保护

- 敏感配置使用环境变量
- 日志中不记录密码等敏感信息
- 数据库加密存储敏感数据
- 定期轮换密钥

### 3. HTTPS强制使用

确保所有认证相关接口都通过HTTPS访问：

```nginx
# Nginx配置
server {
    # 强制HTTPS
    if ($scheme != "https") {
        return 301 https://$host$request_uri;
    }
}
```
