# 拓展——小程序与多平台部署

当你已经有了Web应用后，如何让更多用户方便地访问？小程序和PWA是两种值得考虑的方案。这一章将带你了解多平台部署的思路和实现方法。

---

## 一、微信小程序

### 1. 微信小程序简介

微信小程序是微信生态内的轻量级应用，用户无需下载即可使用。它具有以下优势：
- **流量入口**：微信海量用户，入口丰富（搜索、分享、公众号等）
- **使用便捷**：无需下载，扫码即用
- **社交属性**：易于分享传播
- **支付能力**：支持微信支付

### 2. 开发方式

**原生开发**：
- 使用微信小程序原生框架（WXML、WXSS、JavaScript）
- 文档：https://developers.weixin.qq.com/miniprogram/dev/

**跨平台框架**：
- **Taro**：支持React/Vue语法，编译到多平台
- **Uni-app**：Vue语法，一套代码发布到多平台
- **uni-app**（推荐）：生态完善，支持小程序、H5、App

### 3. Uni-app开发示例

**项目创建**：
```bash
# 安装HBuilderX或使用CLI
npm install -g @vue/cli-init

# 创建项目
vue init dcloudio/uni-app my-project

# 进入目录
cd my-project

# 运行到微信开发者工具
npm run dev:mp-weixin
```

**页面结构**：
```vue
<template>
  <view class="container">
    <view class="title">欢迎使用</view>
    <button @click="callApi">调用后端API</button>
  </view>
</template>

<script>
export default {
  data() {
    return {
      title: 'Hello'
    }
  },
  methods: {
    callApi() {
      uni.request({
        url: 'https://yourapi.com/api/data',
        success: (res) => {
          console.log(res.data)
        }
      })
    }
  }
}
</script>

<style>
.container {
  padding: 20px;
}
.title {
  font-size: 20px;
  font-weight: bold;
  margin-bottom: 20px;
}
</style>
```

### 4. 后端API适配

小程序调用后端API需要注意：

**域名要求**：
- 必须使用已备案的域名
- 仅支持HTTPS
- 需要将域名添加到微信白名单

**跨域处理**：
```python
# 后端添加CORS头
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://servicewechat.com"],
    allow_credentials=True,
)
```

**用户登录**：
```python
# 小程序登录流程
# 1. 小程序调用wx.login()获取code
# 2. 发送code到后端
# 3. 后端调用微信API换取openid
# 4. 创建用户并返回Token
```

## 二、支付宝小程序

### 1. 支付宝小程序简介

支付宝小程序是支付宝生态内的轻量级应用，适合需要支付能力的场景。

**特点**：
- **支付能力**：原生支持支付宝支付
- **商业场景**：适合电商、交易类应用
- **信用能力**：可接入芝麻信用

### 2. 开发方式

**开发工具**：支付宝小程序开发者工具

**框架选择**：
- 原生小程序开发
- 使用支付宝小程序兼容的跨平台框架

### 3. 注意事项

- 需要企业或个体工商户资质才能入驻
- 需要申请支付宝开放平台账号
- 支付功能需要签约商家号

## 三、抖音小程序

### 1. 抖音小程序简介

抖音小程序是字节跳动生态内的应用，基于抖音/今日头条等平台。

**优势**：
- **流量巨大**：抖音海量日活用户

### 2. 开发方式

- 使用字节跳动小程序开发者工具
- 使用uni-app等跨平台框架（需配置字节跳动平台）

## 四、跨平台部署策略

### 1. 技术选型

如果你想一次开发、多端运行，推荐以下方案：

| 框架 | 支持平台 | 适用场景 |
|------|---------|---------|
| Uni-app | 微信、支付宝、抖音、H5、App | 国内小程序为主 |
| Taro | 微信、支付宝、抖音、京东、H5、RN | React技术栈 |
| Flutter | iOS、Android、Web、桌面 | 追求性能 |
| React Native | iOS、Android | React技术栈 |

### 2. 后端统一设计

无论前端有多少平台，后端API应该统一：

```
        ┌──────────────┐
        │   微信小程序   │
        └──────┬───────┘
               │
        ┌──────▼───────┐
        │   统一API    │
        └──────┬───────┘
               │
    ┌──────────┼──────────┐
    │          │          │
┌───▼───┐  ┌───▼───┐  ┌───▼───┐
│数据库 │  │ 缓存  │  │ 文件  │
└───────┘  └───────┘  └───────┘
```

### 3. 响应式设计

H5版本需要适配不同屏幕尺寸：

```css
/* 响应式布局 */
.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 20px;
}

/* 移动端适配 */
@media (max-width: 768px) {
  .container {
    padding: 10px;
  }

  .sidebar {
    display: none;
  }
}
```

## 五、PWA渐进式Web应用

### 1. 什么是PWA

PWA（Progressive Web App，渐进式Web应用）是一种让Web应用具有原生应用体验的技术。

**特点**：
- **可安装**：可以添加到手机桌面
- **离线可用**：支持Service Worker缓存
- **推送通知**：支持消息推送
- **秒开体验**：类原生应用的加载速度

### 2. PWA核心要素

**Web App Manifest**：
```json
{
  "name": "我的AI应用",
  "short_name": "AI应用",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#007bff",
  "icons": [
    {
      "src": "/icons/icon-192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "/icons/icon-512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ]
}
```

**Service Worker**：
```javascript
// sw.js
const CACHE_NAME = 'my-app-v1';
const urlsToCache = [
  '/',
  '/index.html',
  '/static/js/main.js',
  '/static/css/main.css'
];

// 安装事件
self.addEventListener('install', event => {
  event.waitUntil(
    caches.open(CACHE_NAME)
      .then(cache => cache.addAll(urlsToCache))
  );
});

// 拦截请求
self.addEventListener('fetch', event => {
  event.respondWith(
    caches.match(event.request)
      .then(response => response || fetch(event.request))
  );
});
```

**注册Service Worker**：
```javascript
if ('serviceWorker' in navigator) {
  window.addEventListener('load', () => {
    navigator.serviceWorker.register('/sw.js')
      .then(registration => {
        console.log('SW registered:', registration);
      })
      .catch(error => {
        console.log('SW registration failed:', error);
      });
  });
}
```

### 3. PWA vs 小程序

| 特性 | PWA | 小程序 |
|------|-----|-------|
| 无需下载 | ✓ | ✓ |
| 跨平台 | ✓（浏览器） | ✗（各平台独立） |
| 推送通知 | ✓ | ✓（有限制） |
| 支付能力 | ✗ | ✓ |
| 流量入口 | 搜索引擎、分享 | 平台内搜索、扫码 |
| 开发成本 | 较低 | 较高（多平台） |

## 六、移动端适配建议

### 1. 响应式设计

确保Web应用在不同设备上都能良好显示：

- 使用CSS Grid/Flexbox布局
- 使用相对单位（rem、vh、vw）
- 设置viewport meta标签

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
```

### 2. 触摸优化

- 按钮足够大（至少44x44像素）
- 避免hover依赖（移动端无hover）
- 使用touch事件

```javascript
element.addEventListener('touchstart', (e) => {
  // 处理触摸
}, { passive: true });
```

### 3. 性能优化

- 图片懒加载
- 减少HTTP请求
- 启用Gzip压缩
- 使用CDN加速
